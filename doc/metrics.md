# Success Metrics

## Product Success Metrics

### Decision Quality
- percentage of recommendations approved as-is
- percentage of recommendations modified
- percentage of recommendations rejected
- false positive and false negative review findings

### Workflow Efficiency
- average time to evaluate an application
- number of applications reviewed per cycle
- reduction in manual analysis effort

### Data Quality
- percentage of records with complete required fields
- number of stale data warnings
- number of low-confidence recommendations caused by missing data

## SQDC Alignment

### Safety
Reduce risk from unsupported, vulnerable, or poorly governed applications.

### Quality
Improve consistency, transparency, and defensibility of portfolio decisions.

### Delivery
Accelerate application review and planning cycles.

### Cost
Identify redundant, low-value, or high-cost applications for retirement or consolidation.

## Demo Metrics
For the prototype, track:
- total applications
- recommendations by category
- high-risk recommendations
- reviewer approvals, modifications, and rejections
- low-confidence recommendations
